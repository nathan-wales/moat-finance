MOAT FINANCE LOCAL

Download the desktop app

Moat Finance Local keeps your financial data in a SQLite database on your computer. Fully offline capable. No cloud database. No remote account storage. Free, with public source code.

All platforms

Choose your operating system if auto-detection does not match your device.

macOS Apple Silicon Download .dmg macOS Intel Download .dmg Windows Coming soon Join waitlist Linux AppImage Download AppImage

macOS

Open the .dmg and drag Moat Finance to Applications. On first launch, macOS may ask you to confirm the app is from a verified developer (requires a signed and notarized build).

Windows

The Windows desktop app is coming soon. Join the waitlist and we will email you when it is ready.

Linux

Make the AppImage executable, then run it: chmod +x Moat*.AppImage && ./Moat*.AppImage. No system-wide install required.

# Code of Conduct

Moat Finance adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## In short

- Be respectful and welcoming, whatever someone's background or experience level.
- Give and accept constructive feedback gracefully.
- No harassment, personal attacks, trolling, or publishing other people's private information.
- Personal finance is personal: never ask contributors or users to share their own financial data, and never post real financial data in issues, screenshots, or test fixtures.

## Scope

This applies in all project spaces, including issues, pull requests, discussions, and any official community channels, and when someone represents the project in public.

## Reporting

Report unacceptable behavior to **hello@moatfinance.ai**. Reports are handled confidentially. Maintainers may remove content, warn, or temporarily or permanently ban anyone who violates this code, following the Contributor Covenant's enforcement guidelines.

# Backlog

This is the low-friction dumping ground for rough ideas, early explorations, and "we should think about this" notes.

**No formatting required.** Drop ideas here as bullet points, rough notes, or partial thoughts.

When an idea is prioritized, promote it to `specs/features/[name]/spec.md`. See [../README.md](../README.md) for the full spec template, agent workflow, and quality bar.
